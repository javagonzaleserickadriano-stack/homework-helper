Política de Privacidad de TareaFast

Última actualización: 1 de mayo de 2026

1. Información que recopilamos

TareaFast utiliza cookies de Google AdSense para mostrar anuncios. No solicitamos nombres, correos ni datos personales para usar la herramienta.

2. Uso de Google AdSense

Utilizamos Google AdSense para mostrar anuncios. Google usa cookies para publicar anuncios basados en visitas anteriores a nuestro sitio web. Los usuarios pueden inhabilitar la publicidad personalizada en la Configuración de Anuncios de Google.

3. Datos de terceros

Los problemas de matemáticas que ingresas son enviados a la API de OpenAI únicamente para generar la solución. No almacenamos tus preguntas.

4. Contacto

Para cualquier duda sobre esta política, contáctanos en: tareafast.oficial@gmail.com
